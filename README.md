# PatentPulse
Advanced Java research submission, file integrity verification, and review management system

## Administration

The administrator user-management view is available at
`src/main/webapp/WEB-INF/views/users.jsp`, with its styles in
`src/main/webapp/assets/admin-users.css`. It displays account roles and status, and
provides controls to change researcher/reviewer access and enable or disable accounts.
Administrator accounts are shown as protected and cannot be edited from this view.
